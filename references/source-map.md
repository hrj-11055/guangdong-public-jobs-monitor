# 官方信息源地图

## 覆盖方法

“信息源全”按可审计覆盖定义，不按搜索引擎结果数量定义：

1. 用国家、省、市人事综合管理与公务员主管平台兜底首发公告。
2. 用广东 21 个地级市主管机关栏目补齐各地自行招聘与属地后续。
3. 用报名系统、人事考试页面补齐确认、准考证和成绩节点。
4. 用广州 11 个区的招聘栏目补齐资格复审、面试、体检和公示。
5. 用教育、卫生健康、国资和公告指定的单位官网补齐专业岗位后续。

2024 年国家事业单位招聘规则要求，招聘公告、补充公告经备案后须在事业单位人事综合管理部门招聘平台公开发布；因此汇总平台是覆盖基线，单位官网是后续加密层，不能倒置。

## 权威等级

- `A`: 法定或主管机关首发/汇总平台，必须每日成功检查。
- `B`: 广州区级或行业主管部门官方栏目，必须每日检查。
- `C`: 官方报名、公共招聘或国企补充平台，用于补漏或操作，不单独决定岗位性质。
- `D`: 非政府报名服务平台。仅在官方公告明确链接时使用，不作为事实原始来源。

机器可读的完整清单见 [official-sources.json](official-sources.json)。当前清单包含国家、省、广东 21 个地级市、广州 11 区和重点行业层。每条记录包括权威级别、地区、用途、核验日、监控频率与限制。

## 必查主干

| 范围 | 主干来源 | 主要用途 |
|---|---|---|
| 国考 | 国家公务员局年度专题 | 公告、职位表、指南、大纲、报名、补录 |
| 中央事业单位 | 人社部公开招聘服务平台、中国公共招聘网 | 中央事业单位公告与公示 |
| 广东省考 | 广东组织工作网、省人社厅、广东人事考试网 | 公告、职位表、专业目录、大纲、后续安排 |
| 广东事业编 | 省人社厅事业单位招聘栏目、省事业单位报名系统 | 集中招聘与省属单位招聘 |
| 广东各地市 | 21 个地级市人社或政府招聘栏目 | 各市自行招聘、资格复审、面试、体检和公示 |
| 广州市 | 市人社局公务员考录、事业单位招聘栏目 | 广州考区与市属单位全流程 |
| 广州各区 | 11 个区政府招聘栏目 | 区属单位资格复审、面试、体检、公示 |
| 高频行业 | 市教育局、市卫健委、市国资委 | 教师、医疗卫生、国资直属事业单位与国企补漏 |

## 不能混用的来源角色

- 公告首发页：决定岗位性质、条件和时间。
- 报名系统：执行报名、确认、准考证、成绩查询；不能代替公告附件。
- 第三方报名平台：仅是技术通道，必须回链官方公告。
- 商业培训与聚合站：只能发现线索，不得成为 Excel 中的“官方来源”。
- 微信公众号：只有主管部门公告明确列为同步渠道时才作为补充；监控脚本不绕过平台限制抓取公众号。

## 月度补全检查

- 检查年度国考专题是否已切换到新年度路径。
- 检查广东省考、选调生、事业单位集中招聘年度入口。
- 检查广州 11 区栏目是否改版或跳转。
- 从新公告附件提取新出现的招聘单位官网，并人工确认后加入 C 层。
- 检查教育、医疗、高校和国企是否出现只在单位官网发布的后续通知。
- 对失败源记录 HTTP 状态、失败日期和替代官方入口，不删除历史记录。
