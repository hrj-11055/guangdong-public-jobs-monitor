# 信息核验规则

## 最低证据标准

一条可对外使用的记录至少要有：

1. 官方原文 URL；
2. 发布机关或招聘单位；
3. 公告发布日期；
4. 招聘性质的原文证据；
5. 报名截止时间或明确标记“未公布/已截止/长期招聘”；
6. 最近核验时间；
7. 关键附件是否已打开。

缺少其中任一项时，把核验状态设为 `待复核`，不要用常识补齐。

## 来源优先级

按以下顺序裁决冲突：

1. 最新的更正、补充、暂停或取消公告；
2. 招聘主管机关或用人单位原始公告；
3. 同级组织、人社或考试主管部门同步公告；
4. 官方报名系统提示；
5. 官方公共招聘平台转载；
6. 第三方平台，只作线索。

记录旧值、最新值、变更公告 URL 和变更时间。不得静默覆盖。

## 招聘性质证据

- 只有原文出现“公务员录用”或职位表属于公务员招录时标记 `公务员`。
- 只有原文明确“参照公务员法管理”时标记 `参公`。
- 只有原文明确“事业单位编制、事业编制、编制内、获聘人员为事业单位编制人员”等时标记 `事业编`。
- 出现“雇员、编外、辅助人员、合同制、劳务派遣、政府购买服务”时优先标记 `编外`。
- 国资背景企业劳动合同岗位标记 `国企`，不使用“企业编制”暗示行政或事业编制。
- 无法判断时标记 `待核实` 并保留原文摘录。

## 时间规则

- 使用北京时间 `Asia/Shanghai`。
- 记录日期和具体时分；只有日期时不得自行补成 23:59。
- 报名、确认、缴费、准考证、考试分别建时间点，不能只保留报名截止日。
- “预计”“另行通知”“以准考证为准”按原文记录，不转换成确定日期。
- 每次报告都写“截至 YYYY-MM-DD HH:mm 核验”。

## 附件与材料

必须打开职位表、报考指南、专业目录、考试大纲和资格复审清单。若附件无法打开，记录失败，不凭正文摘要猜测岗位条件。

常见报名/复审材料仅作为检查框架，最终以具体公告为准：

- 有效身份证件；
- 报名登记表、准考证和照片；
- 学历、学位证书及学信网材料；
- 国境外学历学位认证；
- 就业推荐表、成绩单、学生证；
- 户口簿或居住证明；
- 工作经历证明、劳动合同、社保记录；
- 党员、基层项目、退役、职称、职业资格等岗位证明；
- 在职在编人员单位同意报考证明；
- 公告要求的承诺书和其他材料。

## 考试资料边界

- `官方大纲`: 可以标为官方考试资料。
- `专业参考目录`: 用于判断专业，不是复习教材。
- `报考指南`: 用于报名与资格判断，不是复习教材。
- 公告明确“不指定教材、不举办或委托培训”时，写入 `无指定教材`。
- 任何真题、模拟题或培训资料都不得标成“官方”，除非发布机关明确发布。

## 隐私

公开仓库不得保存个人证件号码、联系方式、住址、材料扫描件、报名截图或已填写的个人条件。只保存空模板、公开公告和公开岗位信息。
